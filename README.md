# Sorting Algorithms in Java

Welcome to the **Sorting Algorithms in Java** repository!  
This project contains implementations of the most fundamental sorting algorithms, written in clean and well-documented Java code. It is designed for students, developers, and anyone interested in understanding how sorting works under the hood.

---

## 📚 Algorithms Included

- **Bubble Sort**  
- **Selection Sort**  
- **Insertion Sort**  
- **Merge Sort**  -> Currently Unavaliable 
- **Quick Sort**  
- **Shell Sort**

Each algorithm is implemented with clarity and simplicity, making it easy to study, compare, and experiment with.

---

## 🛠️ Features

- Pure Java implementations (no external libraries required)  
- Examples of usage included in `Main.java`  
- Easy to extend with additional algorithms
